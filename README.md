# ospr
This repo holds my basic "default" [Hyprland](https://hypr.land) config for my primary/main laptop.

This config is ***not*** intended to be a fully personalized project that is "released". This is simply where I store the config I use routinely. 
As such, I will not be able to credit every user I've borrowed/taken snippets from, as this config is an amalgamation of lots of different small tweaks.

Naturally, as this is the config for my main laptop, it will also be filled out to fit that system's needs.
Once again, this is ***not*** a "copy the repo and go" config, there will almost certainly be conflicts if you do not use the same applications that I do.

I will note that there are three keymaps in this config that do *completely remap* keps:
    - The *End* key is remapped to *Play/Pause Multimedia*.
    - The *Home* key is remapped to *Previous/last Multimedia*.
    - The *Insert* key is remapped to *Next/Skip Multimedia.*
This is simply because I never use those keys, and wanted baked in music control.
