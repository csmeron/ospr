# ospr
This repo holds my basic "default" [Hyprland](https://hypr.land) config for my primary/main laptop.

This config is ***not*** intended to be a fully personalized project that is "released". This is simply where I store the config I use routinely. 
As such, I will not be able to credit every user I've borrowed/taken snippets from, as this config is an amalgamation of lots of different small tweaks.
