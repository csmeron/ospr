# ospr
This repo holds my basic "default" [Hyprland](https://hypr.land) config for my primary/main laptop.

This config is ***not*** intended to be a fully personalized project, and many of the snippets used in this config are not of my own creation. This is simply where I store the config I use routinely. I will not be able to credit everyone, as this config is an amalgamation of lots of different small tweaks.
